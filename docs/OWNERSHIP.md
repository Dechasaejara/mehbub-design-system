# Hybrid ownership model

Suggested repository boundaries:

| Asset | Default owner/control | Recommended location |
|---|---|---|
| Generic component engine | Agency | Agency core monorepo |
| Generic utilities and token schema | Agency | Agency core monorepo |
| Client logo, brand fonts, photography | Client, subject to license | Client brand repo/package |
| Client-specific token values | Governed by client contract | Client brand repo/package |
| Bespoke project feature | Defined in statement of work | Client application repo |
| Reusable generic improvement | Agency if contract permits | Agency core via review |

This is an operational model, not a substitute for legal review. Ensure each contract states ownership, license, source delivery, reuse rights, third-party asset licensing, and post-termination access.
